# daily-routine-timer

Source of https://daily-routine-timer.vercel.app (Vercel project `daily-routine-timer`).
This orphan branch lives in the egg-breaker-adventure repo only because this session could not create a new repository; move it to its own repo when convenient.

- `index.html` — the app (two routines: Control, Anti-snore)
- `voice/*.mp3` — guided voice tracks, one continuous file per routine, generated by `tools/gen-voice.py` (Piper TTS, LibriTTS speaker 14). Cue timing in the audio mirrors the phase/cue definitions in `index.html`; regenerate the audio whenever those change and copy the new `leads` from `voice/timeline.json` into `LEADS` in `index.html`.
- `api/sync.js` — placeholder sync endpoint (503 until a store is configured)
- `vercel.json` — `git.deploymentEnabled:false` so pushes here never trigger a deploy of the *game* project; deploy via the Vercel API with `gitSource` pointing at this branch.
