# Learnings (one line each, newest first; prune lines that stop being true)
- 2026-11-27 Composio's dashboard has no "set as default" for toolkit accounts (only Reconnect/Disconnect), so a game account can never safely share a toolkit with the other business. YouTube for the game needs a separate Composio account or stays on hold.
- 2026-11-27 The Composio workspace is shared with the owner's other business (top priority). Adding a second account to a toolkit makes the NEW one the default and can redirect their flows. Never add accounts to toolkits they use (youtube, facebook, instagram, metaads, google_analytics, zoho_mail); the game-only toolkits are gmail (eggsmash-mail), googleads, browser_use.
- 2026-11-27 Composio YouTube uses a shared Google API quota; it can be exhausted (403 quotaExceeded) and resets at midnight Pacific.
- 2026-11-27 X's "Unlock more on X" after posting is the Premium upsell, not a bot challenge. Real stop signals: captcha, "unusual activity", rate-limit, follow-limit screens.
- 2026-11-27 Playwright recordVideo records at CSS size and pads; use the CDP screencast (tools/capture-clips.js) for device-resolution video.
- 2026-11-27 Google Ads: GAQL change_event only goes back 30 days; campaign has no start_date field in v26. Check change_event before calling a zero-impression week a bug.
- 2026-11-27 Umami Cloud share API now lives under the region path (/analytics/eu/api) and needs header x-umami-share-context: 1; tools/umami-funnel.js handles both.
- 2026-11-27 Verify analytics on the live site with Playwright, intercepting cloud.umami.is/api/send (fulfill locally so nothing is recorded). Source review alone missed a hoisting bug for months.
- 2026-11-27 Scheduled-task prompt edits from a session are refused by the permission checker; owner pastes them.
- 2026-11-27 create_trigger cannot attach connectors here; owner adds Repository + Gmail + Composio in the task's Edit dialog.
- 2026-11-27 X has no free API tier since Feb 2026; posting goes through Composio browser_use with a persistent logged-in profile. First login needed an e-mailed code.
- 2026-11-27 Play API returns only reviews from the last 7 days; older reviews need Play Console UI.
- 2026-11-27 Two GCP projects exist ("Egg Breaker Adventures" and "... Revival"); the service account lives in Revival (214867732250). Enabling an API in the wrong one looks like success.
- 2026-11-26 x.com, developer.x.com and Umami docs refuse automated fetches from the cloud (402/404). Use the hosted browser or ask for a desktop prompt.
- 2026-11-26 Fresh clone: `npm ci` before `node build.js`. Browser tests need executablePath /opt/pw-browsers/chromium in the cloud container.
- 2026-11-27 A brand-new X account gets an "Unlock more on X" human-check screen after its first post; treat it as a stop signal for engagement, posting itself went through.
